## 项目功能介绍

AI 行业日报看板是一个**单文件、零依赖**的资讯聚合页面，模仿编辑部刊物的视觉风格（米白底 + 砖红/苔绿/墨蓝点缀 + Georgia 衬线标题），将每日 AI 行业资讯以「编辑看板」的形式呈现。

### 核心能力

| 模块 | 说明 |
|------|------|
| 📰 资讯流 | 12 条精选资讯，覆盖模型/产品/融资/政策/研究/开源/人物 7 大分类 |
| 📊 数据概览 | 今日资讯数、热门话题、活跃公司、关键事件四宫格 |
| 🔍 检索筛选 | 关键词搜索 + 分类筛选 + 时间/热度排序 + 列表/网格视图切换 |
| 🧩 模型详情 | 展开后显示规格表、能力进度条、SVG 雷达图、API 成本计算器 |
| 🚀 模型对比 | 多选最多 4 个模型，弹出对比表 + 叠加雷达图，自动高亮最优值 |
| 🛒 产品详情 | 功能/价格/评分/简介四 Tab 切换，含星级打分与成本估算 |
| ★ 收藏夹 | 一键收藏资讯，顶部徽章计数，模态框集中管理 |
| 📈 侧边栏 | 热搜榜、分类分布柱状条、行业人物语录（悬浮吸顶，不随正文滚动） |
| ⬆ 回到顶部 | 页面右侧悬浮按钮，滚动超过 300px 出现，点击平滑回顶 |

### 设计理念

- **编辑刊物风**：VOL. 期号、编者按、引用块、Georgia 衬线标题，弱化科技感
- **暖色调浅色主题**：米白 `#f6f2ea` 底色 + 暖白卡片，砖红主色 `#b85c2b`
- **首部卡片化**：header 从扁平分隔线升级为渐变背景卡片，顶部装饰条 + 放大 Logo/标题，字号加大、视觉醒目
- **悬浮侧栏**：右侧栏 `position: sticky` 吸顶，滚动正文时侧栏固定不动，内容超长时内部独立滚动
- **微交互丰富**：能力条入场动画、Logo 扫光、卡片左侧色条、Tab 淡入、Toast 反馈、回到顶部按钮淡入

## 文件结构

```
workbuddywork/
├── index.html      # 全部代码（HTML 结构 + CSS 样式 + JS 逻辑）
└── README.md       # 项目说明文档（本文件）
```

项目采用**单文件架构**：所有 HTML、CSS、JavaScript 内联在 `index.html` 中，无外部依赖、无构建步骤、无 CDN 引用。

### index.html 内部组织

```
index.html
├── <head>
│   └── <style>          # 全部样式（约 700 行）
│       ├── :root 变量    # 设计 token（颜色/圆角/阴影）
│       ├── 顶部/概览     # header / stats
│       ├── 工具栏/筛选    # toolbar / chips
│       ├── 卡片/详情      # card / detail / spec-table / radar
│       ├── 对比/模态框    # compare-drawer / modal / cmp-table
│       └── 响应式         # @media 880px
│
└── <body>
    ├── .wrap            # 主容器
    │   ├── header.top   # 卡片化首部：放大 Logo + 渐变标题 + 期号 + 收藏夹 + 日期
    │   ├── .editor-note # 编者按
    │   ├── .stats       # 四宫格概览
    │   └── .layout      # 主区 + 悬浮侧边栏
    │       ├── main     # 工具栏 + 筛选 + 新闻列表
    │       └── aside    # 悬浮吸顶：热搜/分类分布/今日语录（自适应填满）
    │
    ├── .compare-drawer  # 底部对比抽屉
    ├── .modal-mask × 2  # 对比模态框 + 收藏夹模态框
    ├── .toast           # 提示气泡
    ├── .back-to-top     # 右侧悬浮回到顶部按钮
    │
    └── <script>         # 全部逻辑（约 800 行）
        ├── 数据层        # NEWS 数组（12 条示例）
        ├── 状态层        # state 对象（筛选/排序/收藏/对比）
        ├── 渲染层        # render / renderCard / renderModelDetail ...
        ├── 交互层        # 事件监听（点击/输入/键盘/滚动/回顶）
        └── 工具函数      # showToast / toggleCompare / updateFavCnt ...
```

## 如何打开网页

本项目**无需安装任何环境**，三种方式任选其一：

### 方式 1：双击打开（最快）

直接双击 `index.html`，系统默认浏览器即可打开。

### 方式 2：拖入浏览器

将 `index.html` 文件拖入任意现代浏览器窗口（Chrome / Edge / Firefox / Safari）。

### 方式 3：本地服务器（推荐用于开发调试）

若需热更新或避免某些浏览器对本地文件的限制，可启动一个简易本地服务器：

```bash
# Python 3
python -m http.server 8000

# 或 Node.js（需先 npm i -g serve）
serve .

# 或 PowerShell 内置
cd D:\computer\workbuddywork
python -m http.server 8000
```

然后浏览器访问 `http://localhost:8000`。

### 浏览器兼容性

| 浏览器 | 最低版本 | 备注 |
|--------|----------|------|
| Chrome | 90+ | 推荐 |
| Edge   | 90+ | 推荐 |
| Firefox | 88+ | |
| Safari | 14+ | macOS/iOS |

不支持 IE。

## 已实现的交互功能

### 1. 资讯浏览

- **分类筛选**：点击顶部 chip 切换分类（全部/模型/产品/融资/政策/研究/开源/人物），实时过滤
- **关键词搜索**：输入框实时搜索标题、描述、来源、关键词（200ms 防抖）
- **排序切换**：「最新」按时间倒序 / 「最热」按热度降序
- **视图切换**：「列表」单列纵排 / 「网格」双列卡片
- **关键词标签点击**：点击卡片底部 `#关键词` 直接以此搜索
- **已读标记**：展开过的卡片标题后显示「已读」徽章

### 2. 模型详情（type: model）

- **规格表**：参数量 / 上下文 / 价格 / 综合评分四宫格
- **能力进度条**：数学推理、代码生成、中文理解、长文档等，带 cubic-bezier 入场动画
- **SVG 雷达图**：4 层背景网格 + 数据多边形 + 顶点 + 标签
- **API 成本计算器**：滑动条选择每日 tokens（0-100M），实时计算日/月成本

### 3. 模型对比

- **进入对比模式**：点击工具栏「⇄ 对比」按钮，所有模型卡片右上角出现勾选框
- **多选上限**：最多 4 个模型，超出时 Toast 提示
- **底部抽屉**：已选模型以 chip 形式列出，可单独移除或一键清空
- **对比模态框**：
  - 表格对比参数/上下文/价格/评分/各维度能力
  - **最优值自动高亮**（砖红色加粗）
  - 底部**叠加雷达图**（4 色多边形 + 图例）
- **ESC 键**关闭所有模态框

### 4. 产品详情（type: product）

- **四 Tab 切换**：功能 / 价格 / 评分 / 简介，带淡入动画
- **功能列表**：双列布局，悬停高亮
- **价格卡片**：定价 + 说明
- **API 成本计算器**：同模型
- **星级评分**：5 星交互打分，实时更新分数与投票人数

### 5. 收藏夹

- **收藏按钮**：卡片底部 ★ 按钮，点击切换收藏状态
- **顶部徽章**：实时显示收藏总数
- **收藏夹模态框**：集中查看所有收藏，支持单项移除

### 6. 视觉与微交互

- **卡片化首部**：渐变背景 + 顶部彩色装饰条 + 圆角边框 + 阴影，从扁平分隔线升级为独立区块
- **渐变标题**：「AI 行业日报」使用墨黑→砖红渐变文字效果，字号加大至 44px
- **放大 Logo**：72×72 尺寸 + 加深阴影，视觉锚点更突出
- **日期卡片**：白底圆角卡片 + 阴影，字号 22px，强化时间感
- **悬浮侧栏**：`position: sticky` 吸顶，滚动正文时侧栏固定不动；内容超长时内部独立滚动，滚动条美化
- **面板自适应**：侧栏面板 `flex: 1 1 auto`，剩余空间均匀分配，无底部空洞
- **回到顶部按钮**：固定右下角，滚动超 300px 淡入，hover 变橙上浮，点击平滑回顶
- **Logo 扫光动画**：4 秒循环一次的高光扫过
- **实时更新指示灯**：绿色圆点脉冲呼吸
- **卡片左侧色条**：hover/展开时从顶部展开
- **概览卡片**：hover 时左侧色条上升 + 上浮
- **能力条入场**：卡片展开时从 0% 动画到目标值
- **Tab 切换**：淡入 + 上移过渡
- **Toast 反馈**：收藏/打分/加入对比/超限等操作即时提示
- **关键词悬停**：变砖红 + 边框

### 7. 响应式

- ≤880px 自动折叠为单列布局
- 概览变为 2×2 网格
- 雷达图在小屏隐藏（仅保留进度条）
- 规格表/功能列表变单列

## 后续可以扩展的功能建议

以下是按优先级排列的扩展方向，可直接基于现有架构迭代：

### P0 - 数据层（让看板真正可用）

- **接入真实数据源**
  - RSS/Atom 订阅：36氪、机器之心、Hugging Face Blog、OpenAI Blog 等
  - GitHub Trending：抓取 AI 相关仓库
  - arXiv API：每日新论文
  - 知乎/微博热搜 API：行业关键词
- **定时自动更新**：每日 09:00 抓取并整理，写入 JSON 数据文件
- **后端服务**：可选 Node.js/Python 简易服务，提供 `/api/news` 接口
- **数据持久化**：localStorage 保存已读/收藏/评分状态，刷新不丢失

### P1 - 检索与导航

- **日期范围筛选**：增加日期选择器，查看历史日报
- **来源筛选**：按媒体/官方/论文/社交等来源过滤
- **热度阈值**：只看热度 > X 的资讯
- **高级搜索**：支持 `AND/OR/NOT` 布尔表达式
- **归档页**：VOL.247、VOL.246 等历史期号浏览

### P2 - 内容深化

- **原文链接**：每条资讯增加「阅读原文」跳转
- **相关推荐**：基于关键词相似度推荐关联资讯
- **AI 摘要**：接入 LLM 自动生成每条资讯的 TL;DR
- **每日早报邮件**：订阅后每日推送精选摘要到邮箱
- **RSS 输出**：生成 `/feed.xml` 供订阅器消费

### P3 - 模型对比增强

- **基准测试数据**：接入 MMLU、HumanEval、MATH 等公开基准
- **价格走势**：模型 API 价格历史曲线
- **可用性状态**：是否开放注册、排队情况
- **部署方式**：API / 私有化 / 开源权重
- **对比方案保存**：保存常用对比组合，生成分享链接

### P4 - 用户体验

- **深色主题**：增加 dark mode 切换（已有变量系统，易扩展）
- **字体切换**：衬线/无衬线切换
- **密度调节**：紧凑/舒适/宽松三种卡片密度
- **快捷键**：`/` 聚焦搜索、`g` 切换网格、`c` 进入对比模式
- **PWA 支持**：可安装到桌面/手机，离线访问
- **多语言**：英文版切换

### P5 - 协作与社区

- **用户系统**：登录后同步收藏/评分到云端
- **社区评分**：聚合所有用户的评分显示综合榜
- **评论**：每条资讯支持短评
- **投稿**：用户可提交新资讯，编辑审核后收录
- **Newsletter 订阅**：邮件/飞书/钉钉推送

### P6 - 数据可视化

- **趋势曲线**：某关键词（如「具身智能」）30 天热度走势
- **公司矩阵**：活跃公司 × 领域的气泡图
- **融资时间线**：近期重要融资事件横向时间轴
- **政策地图**：全球 AI 监管政策分布图
